## What This Does

Interfliqx provides free, agentless security assessments that help businesses identify configuration weaknesses across their public-facing infrastructure.

**Checks include:**

- **Website Security** — HTTPS enforcement, TLS certificates, HTTP security headers (HSTS, CSP, X-Frame-Options)
- **Email Security** — SPF, DKIM, DMARC configuration and enforcement
- **DNS Health** — A, MX, TXT, NS records and DNSSEC validation
- **Microsoft 365 Readiness** — Exchange Online routing, SPF includes, Autodiscover
- **Cloud & Azure Readiness** — Encryption, security headers, DNSSEC
- **Network Security** — TLS protocols, certificate chains, security headers
